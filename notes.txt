            GDT (array of 8-byte descriptors):
                    
                    │ [0] Null Descriptor (required)  │ 8 bytes
                    
                    │ [1] Code Segment (for CPU code)  │ 8 bytes
                   
                    │ [2] Data Segment (for data/stack)│ 8 bytes
                   
                    │ [3] (optional, not needed)    │ 8 bytes
                   

BYTE layout - 
0-1   =  limit  L16
2-3   =     base L16
4   = base m8
5  = access byte
6-7   = limit H4 and flags


Bit 7: Present (1 = descriptor is valid)
Bit 6: Privilege level (0 = kernel, 3 = user)
Bit 4: Type (1 = code/data, 0 = system)
Bit 3: Executable (1 = code, 0 = data)
Bit 2: Direction (0 = grow up)
Bit 1: Writable (1 = readable/writable)
Bit 0: Accessed (0 initially)
